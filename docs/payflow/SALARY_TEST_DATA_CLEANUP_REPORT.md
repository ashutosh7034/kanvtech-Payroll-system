## 1. Investigation & Root Cause Analysis

### Identified Test Data
During inspection of the Salary Components Master table (`SalaryComponent`), **40 total records** were present. An investigation query revealed that **24 of these records** were identical test fixtures created during automated integration test runs:

- **Component Name:** `Technical Cert Allowance`
- **Code Pattern:** `TEST_COMP_5687`, `TEST_COMP_4184`, `TEST_COMP_5045`, `TEST_COMP_4565`, `TEST_COMP_2270`, `TEST_COMP_2376`, `TEST_COMP_5135`, `TEST_COMP_4400`, `TEST_COMP_1748`, `TEST_COMP_6444`, `TEST_COMP_9816`, `TEST_COMP_9139`, `TEST_COMP_8622`, `TEST_COMP_2165`, `TEST_COMP_4601`, `TEST_COMP_0998`, `TEST_COMP_2407`, `TEST_COMP_2897`, `TEST_COMP_3922`, `TEST_COMP_6226`, `TEST_COMP_4982`, `TEST_COMP_4233`, `TEST_COMP_3653`, `TEST_COMP_8324`
- **Created Dates:** Between October 14, 2026, and October 15, 2026
- **Origin:** Generated by `backend/tests/matrix50Scenarios.test.ts` (Scenario 2: `const compCode = 'TEST_COMP_' + Date.now().toString().slice(-4)`). In previous test runs that were aborted or crashed prior to `afterAll`, these components remained persisted in the local development database.

### Dependency & Foreign-Key Audit
Before executing any destructive action, a relationship audit was conducted across all potential foreign-key dependents:

| :--- | :--- | :---: |
| `SalaryTemplateLine` | `templateLine.componentId -> component.id` | **0** |

**Conclusion:** The 24 test components were completely unreferenced, disposable test artifacts with zero links to legitimate salary templates, employee compensation assignments, or finalized payroll runs.
